## Broke
- **`php artisan serve` crashed with `Class "PDO" not found`.**
  → Fedora's `composer` package doesn't install PHP database extensions by default.
  → Fixed with `sudo dnf install php-mysqlnd php-pdo`.
  → Lesson: on Fedora, PHP extensions are split into separate packages. Installing `composer` gets you PHP, but not the database drivers.

- **`no such table: sessions` on first page load.**
  → Laravel's default `SESSION_DRIVER=database` expects migrations to have been run.
  → Fixed by setting `SESSION_DRIVER=file` in `.env` for local dev. Simpler for learning; can switch to database sessions later.

- **`ViteManifestNotFoundException`** when loading the Tic-Tac-Toe view.
  → Called `@vite(['resources/css/app.css'])` without running `npm install && npm run build`.
  → Fixed by removing the Vite directive — inline `<style>` covered everything for this project.

- **Confused by `boost.json` and `CLAUDE.md`** in the fresh Laravel project.
  → Realized they're auto-generated by Laravel Boost (Laravel 12+ AI tooling).
  → Removed both for now; will regenerate when wiring up local AI agents.
