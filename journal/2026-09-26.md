# 2026-09-26 — Day 2: Making My Terminal Reproducible

## Did

* Cleaned up my Zsh setup and kept Zinit as the plugin manager.
* Added `zsh-autosuggestions`, `zsh-syntax-highlighting`, `fzf`, and `zoxide`.
* Set up `fzf` for `Ctrl+R` history search and `Ctrl+T` file selection.
* Configured zoxide as `z` and added `zoi()` for interactive directory jumping.
* Installed Starship and built a two-line prompt with username, hostname, directory, Git information, and Python version.
* Made the prompt dynamic instead of hard-coding my username and hostname.
* Created a custom Konsole color scheme for the terminal.
* Started a dotfiles repo and separated terminal configuration from future KDE/DE configuration.
* Wrote `sync.sh` to compare my live configs with the dotfiles and only copy files when their contents actually change.

## Broke

* `zoxide init zsh` created `zi`, which collided with Zinit's existing `zi` command → initialized zoxide with `--cmd z` and kept `zi` for Zinit.
* Starship initially printed values like `yellow` and `green` literally instead of using them as colors → fixed the configuration to use Starship's actual formatting syntax.
* The Starship username wasn't appearing → enabled `show_always`.
* Node appeared in the prompt just because a `package.json` existed → disabled the Node module because I don't want every project to advertise its runtime.

## Next

* Identify which KDE configuration files actually contain my desktop tweaks.
* Add those configs under `DE/kde/`.
* Make the dotfiles repo installable on another machine instead of only being a backup.
* Eventually separate syncing from restoring so I can safely reproduce the setup elsewhere.

I started tweaking my Fedora terminal because I wanted it to feel like mine.

It started with Zsh and slowly turned into a proper terminal setup.

I cleaned up my `.zshrc`, kept Zinit as the plugin manager, added autosuggestions and syntax highlighting, then added `fzf` for history/file search and `zoxide` for smarter directory jumping.

Then came Starship.

I built a two-line prompt showing my dynamic username, hostname, current directory, Git branch/status/commit, and Python version. I also created a custom Konsole color scheme.

Then I asked myself: why spend all this time configuring a terminal if I can't reproduce it?

So I started a dotfiles repo with separate `terminal/` and `DE/` directories.

Finally, I wrote a small `sync.sh` that checks the actual contents of my configs and only copies them when something changed.

The terminal is customized now.

Next step is making the whole environment reproducible.
